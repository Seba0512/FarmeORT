## Claude Code

Las instrucciones del proyecto están en `AGENTS.md` (importado arriba). Es la fuente única que
comparte todo el equipo, incluido quien usa Codex: no agregar reglas en este archivo, cambiarlas en
`AGENTS.md` por PR.

Si están cargadas las skills `da2-*`, usalas para el detalle de cada tema. Si una skill contradice
`AGENTS.md`, prevalece `AGENTS.md` (y por encima de él, la configuración obligatoria de la rama
`repo-configuration` de DA2-Tecnologia). Avisá la diferencia en vez de elegir en silencio.
